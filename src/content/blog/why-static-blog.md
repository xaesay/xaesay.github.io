在搭这个博客之前，我对比了目前主流的免费方案，把结论记录在这里。

## 需求

- 有自己的域名，想绑定使用
- **不想备案**，也不想买服务器
- 国内访客能打开（速度可以慢，但不能 404）
- 免费，或者免费额度足够个人博客用

## 候选方案对比

| 方案 | 国内直连 | 需备案 | 免费额度 | 评价 |
| ---- | -------- | ------ | -------- | ---- |
| Cloudflare Pages | 可访问，速度中等 | 否 | 500 次构建/月，无限静态请求 | ✅ 推荐 |
| Vercel | 不稳定 | 否 | 个人免费 | 国内直连经常失败 |
| Netlify | 不稳定 | 否 | 100GB 流量/月 | 同上 |
| GitHub Pages | 可访问，速度较慢 | 否 | 无限（公开仓库） | 可作备选 |
| 腾讯云 EdgeOne Pages | 快 | 需备案 | 有免费额度 | 域名备案后可选 |

## 结论：Astro + Cloudflare Pages

**Astro** 负责生成纯静态页面——没有数据库、没有后端，意味着：

- 托管零成本：任何静态托管都能放
- 快：页面就是 HTML，秒开
- 安全：没有可以被打的服务端

**Cloudflare Pages** 负责托管和全球 CDN：

- 直接绑定自定义域名，自动配好 HTTPS 证书
- 连接 GitHub 仓库后，`git push` 即自动构建发布
- 每月 500 次构建、静态流量不限，个人博客绰绰有余
- 国内虽然没有节点，但 Cloudflare 的边缘网络国内基本能直连，可用性比 Vercel 好得多

如果将来某天想要极致的国内速度，再给域名做个备案迁移到 EdgeOne Pages 也不迟——
因为是纯静态站，迁移成本几乎为零。

## 留一条后路

静态博客最大的优点就是**自由**：生成的是纯 HTML，任何时候都可以原封不动地搬到
任何其他托管平台。不被任何一家锁定，这就是我选它的底气。
